# EDIS — Education Data Intelligence System

## About the Project
EDIS is a machine-learning-based application designed to predict student academic performance and help identify students who may need additional academic support.

## Features
- Student performance prediction
- Machine learning model integration
- Interactive Streamlit dashboard
- Dataset analysis and visualization

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly

## How to Run
1. Install Python.
2. Install the required libraries.
3. Place the required model and dataset files in the project folder.
4. Run the application:

```bash
python -m streamlit run app.py
```
